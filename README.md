# Signal-Transformation-App
Signal Transformation App

A MATLAB-based signal processing application demonstrating time shifting, time scaling, and time reversal of continuous-time signals.

Features

- Generate and display signals.
- Apply time-shifting operations.
- Perform time scaling.
- Reverse signals in time.
- Compare original and transformed signals graphically.

Requirements

- MATLAB with support for the functions used in the source code.

How to Run

1. Download or clone this repository.
2. Open the project folder in MATLAB.
3. Run "RunSignalTransformApp.m" from the MATLAB Command Window.

Alternatively, run the launcher script from the MATLAB Editor.

Files

- "SignalTransformApp.m" — main application source code.
- "RunSignalTransformApp.m" — launcher script.

Purpose

This project is intended for learning and demonstrating basic time-domain transformations in signal processing.
